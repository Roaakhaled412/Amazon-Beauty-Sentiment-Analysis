# Amazon Beauty Sentiment Analysis

## Project Overview

This project focuses on analyzing customer reviews of Amazon Beauty products using Natural Language Processing (NLP) and Machine Learning techniques to classify customer sentiments and extract meaningful insights from product feedback.

The project explores and compares multiple sentiment analysis approaches, including traditional Machine Learning algorithms and Transformer-based models, to evaluate their performance in understanding customer opinions.

## Objectives

- Analyze customer reviews and identify sentiment patterns.
- Apply text preprocessing and feature extraction techniques.
- Develop sentiment classification models using traditional Machine Learning algorithms.
- Fine-tune and evaluate Transformer-based models for sentiment analysis.
- Compare different models based on their classification performance.
- Explore approaches to improve sentiment classification, particularly neutral sentiment detection.

## Models Implemented

The project includes four experimental notebooks covering different approaches:

### 1. Traditional Machine Learning
- Logistic Regression
- Support Vector Classifier (SVC)
- Naive Bayes

### 2. Transformer-Based Models
- DistilRoBERTa
- RoBERTa
- DeBERTa
